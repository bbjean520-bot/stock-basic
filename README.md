# stock-basic

Cursor Agent Skill：台股／投資基本常識，雙來源為

- [CMoney 財經百科](https://wiki.cmoney.tw/finance/)
- [MoneyDJ 財經百科](https://www.moneydj.com/KMDJ/Wiki/WikiHome.aspx)

## 安裝（個人 skill）

把本目錄複製到：

```text
~/.cursor/skills/stock-basic/
```

或在 Cursor 以 skill 方式匯入本 repo 的 `SKILL.md`。

## 檔案

| 檔案 | 說明 |
|------|------|
| `SKILL.md` | 觸發條件與查閱流程 |
| `core-taiwan.md` | 台股骨架速查 |
| `glossary-cmoney.md` | CMoney 詞條索引 |
| `sources.md` | 兩站差異與 MoneyDJ 查法 |

## 注意

- 非投資建議；行情數據請另接 API（例如 FinMind）。
- 百科原文版權屬原站，僅供查閱摘要與附連結。
